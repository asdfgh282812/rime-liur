# 台灣繁體中文校錯提示原型

使用者已確認試作「選字時提醒」。採用 CKIP ALBERT Tiny，於本機執行，不自動更改已送出的文字。

- 保留原候選順序與空白、數字選字行為。原候選註解顯示「建議：註（備註，Tab 採用）」，Tab 可選擇建議；一般 Tab 保持原行為。
- 僅繁體模式啟用；可於 Rime 選單關閉。模型故障或未安裝時正常輸入照常使用。
- 只使用本次輸入的近期中文作為左上下文。已上屏的 Backspace 只回退一字；組字中的 Backspace、Escape 與候選上下選字保留前文。移動文件游標、非中文輸入與語言切換會清除上下文；閒置 120 秒後只在新組字開始時清除。無法取得文件全文，不提供送出後紅線或整篇校對。
- 只在相關模式選項變更時清除前文；前端顯示選項不清除。連線失敗不快取成「沒有建議」，允許後續重試。維持模型信心門檻及正常詞保護。
- 模型結合同音字候選、既有詞頻資料與台灣用詞，採保守門檻；原詞已存在時不提示，僅評估短詞中最後一字的替換。
- 長上下文無法明確判斷時，回退到候選詞的局部前綴再評分，使用更嚴格門檻（分數差至少 4、條件信心至少 0.90），並保護完整詞的邊界；局部視窗若互相矛盾則不提示。避免前文重複錯字使「備註備住備＋住」永遠漏報，也避免誤改「我準備＋住」。
- 模型常駐獨立程序，Unix domain socket 僅限本機使用者。由獨立 C 連線程式查詢，socket 等待上限 50ms，另計子行程啟動成本；短文字僅經子行程參數傳遞。沒有文字日誌、網路請求或永久輸入紀錄，不載入外部動態函式庫或修改鼠鬚管簽章。
- 原型先測正例與反例及延遲，再以原生 Rime 測試提示、採用、忽略、關閉、無服務與舊功能，備份後才套用。
- 模型與建置依賴不加入 Git。保存來源、版本與模型授權資訊；日常程序僅需 ONNX Runtime、NumPy。

## 2026-10-28 修正：新上下文第一次沒有建議

# 同音字查詢與多國語言輸入

使用者已於對話確認沿用官方操作，並要求直接修正。

- `'` 加蝦米碼進入同音字查詢。先以空白或數字選原字，再以空白或數字選同聲調的同音字；多音字合併所有讀音，去除重複字。第二階段 Backspace 返回原查詢，Escape 取消。無讀音時保留原字作為候選。
- `,,c`、`,,ct`、`,,j`、`,,t` 後按空白或 Enter，分別切換簡體字碼、繁碼轉簡、日文、繁體。指令本身不上屏，切換選單也能操作模式。
- 簡體與日文使用現有 liur_TradToSimp、liur_Japan 碼表。日文假名沿用羅馬拼音加逗號（平假名）或句號（片假名），例如 a, → あ、a. → ア。
- 用 Lua 處理操作與分段；由原生 table translator、Memory、ReverseLookup 查詢編譯字典，避免額外複製詞庫。簡體來源字先轉繁體查讀音。
- 不改注音、拼音、造詞、讀音反查的引導鍵。保留嘸蝦米空白選字與一般 Enter 原碼上屏。
- 依現有字典涵蓋範圍提供字碼與讀音，不宣稱與官方商業版詞庫完全相同。
- 在獨立目錄用這台 Mac 的 Rime 與 Lua 外掛驗證後，備份涉及的本機檔案再套用、重新部署。
